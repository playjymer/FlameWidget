# 🔥 FlameWidget MD3 — Android-приложение для адаптивных виджетов рабочего стола

Современное Android-приложение на **Jetpack Compose** в стиле **Material Design 3 (Material You)**, позволяющее создавать красивые, динамически обновляемые и идеально подогнанные по размерам виджеты рабочего стола из любой ссылки на изображение или веб-виджет FlameBot.

---

## 🎯 Адаптивность и подгонка по размерам

На рабочем столе Android виджеты привязаны к сетке лаунчера:
1. **Широкий виджет (4×2)** — идеален для статус-баров, прогресса и баннеров FlameBot.
2. **Квадратный виджет (2×2)** — компактный формат для стриков, счетчиков и карточек.
3. **Автоматическое определение типа**:
   - При вставке ссылки приложение анализирует пропорции изображения и сразу выбирает подходящий формат (широкий 4×2 или квадратный 2×2).
   - Выбор размера больше не сбрасывается при прокрутке экрана.
4. **Независимая настройка каждого виджета**:
   - Каждый размещенный на рабочем столе виджет изолирован и имеет собственные параметры (ссылка, отступы, радиус, действие по клику). Редактирование одного виджета никак не затрагивает другие.
5. **Режимы масштабирования (Scale Modes)**:
   - **`По размеру (Fit)`**: Сохраняет оригинальные пропорции изображения (например, 1:1 или 2:1), центрирует без растяжения и обрезки.
   - **`Размытый фон (Ambient Blur)`**: По центру отображается четкое изображение, а по бокам — стильное мягкое размытие в цвет самого изображения.
   - **`Заполнение (Crop)`**: Заполняет виджет целиком до краев с красивым скруглением.
   - **`Растянуть (FitXY)`**: Растягивает на всю площадь ячейки.

## ⚡ Интеграция со ссылками и автообновление

- 🔗 **Поддержка Deep Link и гиперссылок**:
  - Нажатие на ссылку вида `flamewidget://widget?url=...` или `https://api.flamebot.app/...` в Telegram открывает приложение сразу с подставленной ссылкой.
  - Поддержка системного меню «Поделиться» (Share).
- 📋 **Умный буфер обмена**:
  - При открытии приложения автоматически обнаруживается скопированная ссылка на виджет с возможностью вставить её в один клик.
- 🚀 **Встроенное автообновление через GitHub**:
  - Приложение проверяет наличие свежих релизов на GitHub при запуске.
  - При выходе новой версии предлагает обновиться, скачивает APK в фоне и сразу запускает системную установку.
- 🤖 **Действие по нажатию**:
  - Поддержка мгновенного открытия бота [@flameintgbot](https://t.me/flameintgbot) по тапу на виджет.
  - Быстрое ручное обновление данных по кнопке в углу виджета.

## 🛠 Технологический стек

- **Язык**: Kotlin 1.9.22
- **UI**: Jetpack Compose + Material 3 (BOM 2024.02.01)
- **Виджеты**: AppWidgetProvider + RemoteViews + Bitmap Canvas Rendering (2×2 и 4×2)
- **Фоновая работа**: AndroidX WorkManager (PeriodicWorkRequest)
- **Сеть и кэширование**: OkHttp3 + Coil Compose
- **Архитектура**: MVVM, StateFlow, Coroutines
- **Оптимизация**: R8 / ProGuard Full Mode (размер release APK всего ~1.6 МБ)
